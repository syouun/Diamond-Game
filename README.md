# ダイヤモンドゲーム (Chinese Checkers) - 15駒ルール版

伝統的なボードゲーム「ダイヤモンドゲーム」を、121ノード・各プレイヤー15駒ルール（Spec v1.2準拠）で実装したブラウザゲームです。
`index.html` 1ファイルだけで動作し、インストール不要で PC・スマートフォン・タブレットから遊べます。

---

## 📁 ファイル構成

```
.
├── index.html       # ゲーム本体（HTML5 / JavaScript、単体で動作）
├── README.md        # この説明書
├── .gitignore
├── .gitattributes
└── delete/          # 旧デスクトップ版などの退避ファイル（Web公開には不要）
```

---

## 🎮 遊び方

- **オンライン**: GitHub Pages で公開した URL にアクセスするだけで遊べます（下記の公開手順を参照）。
- **ローカル**: `index.html` をブラウザ（Chrome、Edge、Safari など）で直接開いてください。

---

## 🌐 GitHub Pages での公開手順

1. GitHub のリポジトリページを開き、**[Settings]** → **[Pages]** を開きます。
2. **[Build and deployment]** で以下を設定します。
   - **Source**: `Deploy from a branch`
   - **Branch**: `claude/keen-franklin-62nlvl`（または main）、フォルダは `/ (root)`
3. **[Save]** をクリックし、1〜2分待つと公開 URL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）が表示されます。

## 📋 ゲーム仕様・特徴

- **盤面**: 121ノード（中央正六角形 R=4 ＋ 三角キャンプ L=4 × 6）、6色のカラーパレット
- **15駒ルール**: 初期陣地・ゴールは「キャンプ10マス ＋ 基底辺5マス」＝ 計15マス、駒には1〜15の番号付き
- **対戦人数**:
  - 2人対戦: 緑 (P1) vs 黄 (P2)
  - 3人対戦: 緑 (P1) vs 水色 (P2) vs 橙 (P3)
  - 人間同士、人間 vs AI、AI vs AI（観戦モード）を自由に設定可能
- **AI**:
  - 初級 (Easy): 貪欲法（ゴールへの前進と最長ジャンプを優先）
  - 上級 (Hard): 反復深化ミニマックス ＋ αβ枝刈り（最大3手読み）
- **アシスト機能**:
  - 人間の手番で5秒操作がないと、上級AIが代打ち
  - 自動操作中に盤面をクリックすると即座に解除され、以後は手動操作に固定
- **ルールオプション**:
  - ゴール退出禁止: ゴール内の駒がゴール外へ出る手を禁止（既定ON）
  - 妨害防止ルール: 相手駒の居座りで封鎖された場合、ゴール15マスが埋まり自駒があれば勝利（既定OFF）

## 🗂 delete フォルダについて

`delete/` には、Web 版では使わない旧ファイルを参照・復元用に退避しています。

| ファイル | 内容 |
| --- | --- |
| `main.py` | デスクトップ版（Python / PyQt5） |
| `requirements.txt` | デスクトップ版の依存定義（PyQt5） |
| `setup.bat` / `start.bat` | デスクトップ版のセットアップ・起動用バッチ |
| `open_browser.bat` | ローカルで `index.html` を開くためのバッチ |

デスクトップ版を使う場合は、これらのファイルをルートに戻してから `setup.bat` → `start.bat` の順に実行してください。

# ダイヤモンドゲーム (Chinese Checkers) - 15駒ルール版

伝統的なボードゲーム「ダイヤモンドゲーム」を、121ノード・各プレイヤー15駒ルール（Spec v1.2準拠）で実装したプロジェクトです。

ブラウザでそのまま遊べる **Web版（GitHub Pages対応）** と、PC上でネイティブ動作する **デスクトップ版（Python/PyQt5）** の両方が用意されています。

---

## 🎮 すぐに遊ぶ方法

### 1. ブラウザで遊ぶ（おすすめ・インストール不要）
- **ローカルで起動する場合**:  
  `open_browser.bat` をダブルクリックするか、`index.html` をお使いのブラウザ（Chrome, Edge, Safari など）で直接開いてください。スマートフォンやタブレットでもプレイ可能です。
- **GitHub Pages でオンライン公開する場合**:  
  下記 [GitHub Pages での公開手順](#-github-pages-での公開手順) をご覧ください。

### 2. デスクトップ版（Python + PyQt5）で遊ぶ
1. `setup.bat` をダブルクリック（初回のみ：仮想環境作成と依存関係のインストール）
2. `start.bat` をダブルクリックしてゲーム起動

---

## 🌐 GitHub Pages での公開手順

このリポジトリを GitHub Pages に公開すると、専用URL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）から誰でもブラウザでプレイできるようになります。

1. GitHub のリポジトリページを開きます。
2. 上部メニューの **[Settings]** をクリックします。
3. 左サイドバーの **[Pages]** をクリックします。
4. **[Build and deployment]** の項目で以下を設定します：
   - **Source**: `Deploy from a branch` を選択
   - **Branch**: `claude/keen-franklin-62nlvl`（または main ブランチ）を選択し、フォルダは `/ (root)` のまま **[Save]** をクリック
5. 1〜2分待つとページ上部に公開URL（`https://...`）が表示されます。そのURLにアクセスすれば世界中からプレイ可能です！

## 📋 ゲーム仕様・特徴

- **盤面ジオメトリ**:
  - 121ノード（中央正六角形 R=4 ＋ 三角キャンプ L=4 × 6）
  - 三角格子グリッド線とカラーパレット（水色、紫、緑、赤、橙、黄）
- **15駒ルール**:
  - 初期陣地およびゴールは「キャンプ10マス ＋ 基底辺5マス」＝ 計15マス
  - 駒には1〜15の番号が付与
- **対戦人数**:
  - **2人対戦**: 緑 (P1) vs 黄 (P2)
  - **3人対戦**: 緑 (P1) vs 水色 (P2) vs 橙 (P3)
  - 人間同士、人間 vs AI、AI vs AI（観戦モード）に自由に変更可能
- **AIエンジン**:
  - **初級 (Easy)**: 貪欲法（ゴールへの前進と最長ジャンプ、後方駒優先、往復防止）
  - **上級 (Hard)**: 反復深化ミニマックス ＋ αβ枝刈り（最大3手読み、盤面評価）
- **アシスト機能**:
  - **5秒無操作タイマー**: 人間の手番で5秒操作がない場合、上級AIが代打ち
  - **手動復帰**: 自動操作中に盤面をクリックすると即座に解除され、以後は手動操作に固定
- **ルールオプション**:
  - **ゴール退出禁止**: ゴール内の駒がゴール外へ出る手を禁止（既定ON）
  - **妨害防止ルール**: 相手駒による居座り封鎖時、ゴール全15マスが埋まり自駒があれば勝利（既定OFF）
